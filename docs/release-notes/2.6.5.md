## Highlights

KM Editor 2.6.5 adds editable YAML game dumps, Game Options and per Pokemon held item chances for Sword and Shield, and the Beta Titan Swapper for Scarlet and Violet. It also adds trainer AI flag repair and Mum's starting money, improves custom model previews, and fixes cache reuse, scrolling input and trainer controls.

## Editing And Output

* Game Dump exports readable, editable YAML for every available category across all five games. Named fields and nested records separate editable values from reference information, and large categories split into numbered files at record boundaries.
* Dump Importer accepts YAML through the existing editor validators. Invalid entries identify the file, line, column and field while preserving the previous pending session. Valid reimports replace their own prior batch and retain unrelated edits. Existing CSV, TSV and JSON item price imports remain available.
* Prepared caches are reused after projects reopen. Missing, changed or invalid entries are verified or rebuilt while current output remains separate from reusable base data.
* Trainer search matches the name displayed in the trainer table. Party Pokemon, moves and source metadata no longer produce unrelated results.

## Sword And Shield

* Game Options sets starting values and hides individual selections for all 16 stock options in version 1.3.2. On takes priority over Default; Off excludes a starting choice but leaves it available to players. Hide removes that choice from navigation. Existing saves retain visible player choices, while hidden saved values fall back to the configured start.
* Held Item Chance provides three searchable item choices and separate normal and boosted percentages for each Pokemon and form. It uses the Pokemon editor's selector and search. Each rate group totals at most 100%, with the remainder and empty slots giving no item. Restoring default chances retains the selected items and other Pokemon's settings.
* Custom held item rates apply literally even when the first two slots contain the same item. Pokemon without a custom override retain inherited rates and the original matching slot behavior. Explicit encounter items can still take priority. Refresh and upgrade an installed Gameplay Settings package after changing or restoring Held Item Chance or Game Options.
* Fix AI Flags reviews possible legacy switching selections per trainer or as a batch. It stages the proposed Fire Gym Rival to Switch Pokemon correction through ordinary trainer editing, preserves other flags and unknown bits, and never changes records automatically on load. AI help explains the native script meanings and custom script limits.
* NPC Item Gift includes Mum's starting pocket money with one Amount field from 0 through 9,999,999 and a default of 30,000. The event adds the amount when it runs; this does not directly change an existing save balance. Other supported script edits remain preserved.
* The 60FPS Patch consumes each accepted list input once and retains queued directions through scrolling. Existing output needs the patch reapplied to receive the correction. Base prize money choices show calculated amounts using the last occupied trainer party slot's level x stored rate x 4. Necrozma, Dusk Mane and Dawn Wings retain distinct names and sprites.

## Scarlet And Violet

* Titan Swapper is a Beta Editor for version 4.0.0. Choose a separate battle Pokemon and level for each of eleven phases while retaining the original story actor. The roster includes Klawf, Bombirdier, Orthworm, the edition's Great Tusk or Iron Treads, Dondozo and final Tatsugiri. Full encounter behavior remains pending in game verification, and native Gameplay Options cannot be combined with this editor.
* The five Titan partner teams synchronize supported base form lead changes with their scene actors. Terastallization is blocked for these teams because it can prevent the battle from progressing. Other partner teams keep their existing controls.
* The next editor output can repair eligible older KM owned Titan and Arven edits, including when applying an unrelated edit. Current choices and externally modified files are preserved. Titan phase rows also accommodate longer text without overlapping labels.

## Legends Z-A

* Project reopening reuses prepared cache progress and supported payloads within the selected cache mode and limits. Invalid entries still fall back to their original sources.
* Atomic cache publication retries brief Windows access and sharing failures. The previous complete cache file remains available until replacement succeeds; persistent failures still report normally.

## 3D Model Editor

* Supported custom replacements in the existing game formats use their current geometry, materials, textures and animations for preview and editing. Original comparison and restoration resolve clean base dependencies separately, preserving unrelated resources.
* Preview handles additional BGRA textures, stored mip tails, repeated node labels, incomplete preview triangles and BC7 edge blocks. Malformed or unsupported resources remain rejected rather than being rewritten to fit the preview.
* Supported fire materials use their source colors, textures, linked masks and animation channels. Enabled emission maps retain their authored gain. Fire rendering remains approximate; these improvements do not add geometry, skeleton or animation authoring.

## Interface And Navigation

* Editor guidance and diagnostics have improved translations across all seven interface languages. The welcome hub includes the 2.6.5 notes and a new developer message, with contextual help for Game Options, Held Item Chance, Fix AI Flags and Titan Swapper.

## Release Metadata

* Application, setup, updater and window title metadata identify KM Editor 2.6.5 consistently.
* The Windows release includes the custom x64 setup executable, its updater signature, the updater manifest and checksums.
