## Highlights

KM Editor 2.7.1 adds 34 Sword and Shield restorations, updates restored models and memory support, and fixes evolution item names. Legends Z-A gains city behavior controls and Fashion Unlock, with smoother editing across the app.

## Workspace

* The editing bar stays visible above long sections in the pokemon, Items, and Moves editors. Section navigation accounts for the bar height while the main page handles scrolling.
* Added checks to catch garbled accents in interface text before a desktop build, including translated text.

## Sword And Shield

* Restore 34 more species and forms, including all Paradox pokemon, Koraidon, Miraidon, Farigiraf, Kingambit, the full Baxcalibur line, Mega Baxcalibur, Gholdengo, Wo-Chien, Chien-Pao, Ting-Lu, Chi-Yu, and Archaludon. The catalog now has 423 selectable restorations. These conversions remain In testing.
* New restorations include donor models, animations, cries, sprites, gameplay data, compatible evolution routes, and custom ability support. Gholdengo is available on its own without adding Gimmighoul.
* Update Assets brings newer revisions to Girafarig, Mega Hawlucha, and Mega Malamar while preserving compatible customizations. Mega models and battle framing retain their intended scale.
* Installing an enabled restoration or updating its assets automatically adds guarded model memory support when required, using the Base ExeFS selected in Project Setup. Updating a disabled restoration keeps it disabled. Supported KM Editor ExeFS patches remain compatible when installed or removed in either order.
* pokemon and Trainer choices use gameplay data without repeatedly validating every installed model package. EXP and EV changes avoid unrelated restoration work, and restored native forms retain their correct vanilla yield defaults.
* Evolution item selectors retain items used by evolution routes even when their metadata lacks an evolution flag. Auspicious Armor and Malicious Armor display their game text names in every interface language.

## Scarlet And Violet

* Evolution item selectors retain route-used items and their game text names, including Auspicious Armor and Malicious Armor, in every interface language.

## Legends Z-A

* Behavior adds independent city roaming and Temperament outside Wild Zones controls. Compatible species can roam through their native walking and return routines. Choose Game Default, Aggressive, Gentle, Timid, or Sluggish for ordinary city spawns while keeping base behavior and separate alpha rules.
* Fashion Unlock supports Z-A 2.0.2. Access Outfit & Looks clothing from the first controllable point before choosing a starter. Stage, review, apply, and uninstall through the usual workflow. Hair, makeup, salon progression, and native cutscene restrictions keep their existing rules.
* Evolution item selectors retain route-used items and their game text names in every interface language.
