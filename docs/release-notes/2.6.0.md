## Highlights

KM Editor 2.6.0 adds an animated 3D Model Viewer for Scarlet and Violet, a new welcome hub, six additional themes, and app-specific RAM and VRAM diagnostics. It also expands compatibility editing, improves History and portable output support, and fixes shared output and Z-A TM batch handling.

## Welcome Hub And Settings

* The new welcome hub brings all five games into a persistent sidebar with saved project status, remembered game selection, release notes, and Getting started guidance. Release notes can show all games or the selected game family, always including shared app changes.
* Opening a game through the hub restores its saved paths in Project Setup. Game-data loading and cache preparation wait until you press Validate Paths. You can browse the hub and choose a game without starting that work.
* Settings follows the game selected in the hub. Data Cache groups the family cache controls and Analysis Loading as separate sections. Layout and Themes places layout controls above themes and appearance options below them. Language and Localization follows Updates.
* The hub shows the installed app version and Made by Matroskin credit, plus a From the developer message below the notes. Documentation, GitHub, Full changelog, and Report an issue each open one browser tab. Welcome content is bundled with the app and remains available offline.

## Scarlet And Violet

* The new 3D Model Viewer under Beta Editors displays models inside the editor through DX12 with automatic graphics adapter selection. Browse Pokemon, forms, environment assets, objects, props, and other verified models, then orbit, pan, zoom, reset, or frame the view.
* Animation controls include play, pause, restart, looping, play once, seeking, playback speed, and rest pose. The viewer supports skeletal animation and supported visibility, color, and texture-coordinate tracks, with layered colors and small compressed textures.
* The viewer is read only: it does not edit or export models or write game output. Lighting and curve interpolation are approximate; effects, morph targets, some material channels, and complete shared character assembly remain unsupported. Missing optional animation data leaves supported geometry viewable with a warning. Enable Show Beta Editors in Settings to access it.
* Output remains editable when switching between a single editor and combined editor batches. Shared descriptor and TM control updates preserve compatible ownership records, history, and checkpoints while checking the current files and each editor’s write scope.
* Items now provides individual and bulk Pokemon compatibility controls for TMs. Trainer AI controls consistently handle the shared Double flag, remove the duplicate Raid choice, and correct the Weak description. TM Machine Controls sends staged policy choices through Changes for review and output.

## Sword And Shield

* Items now provides individual and bulk Pokemon compatibility controls for TMs and TRs. TM and TR groups keep their exact machine assignments and bit positions, including machines that teach the same move.
* Advanced editors use clearer status, selection, and action areas with expandable technical details. Starting Items and Catch Cap have roomier scrollable rows, Royal Candy uses descriptive workflow cards, and Fashion Unlock and Gym Uniform Removal remove redundant explanatory tables while retaining their actions and safeguards.

## Legends Z-A

* Items now provides individual and bulk Pokemon compatibility controls for TMs. Batches that enable several moves correctly reserve empty slots per Pokemon and expand the personal table when needed, preserving every requested move and accompanying edit across all three output modes.
* Trainer AI controls expose Basic, Strong, Expert, and Change while preserving other stored flags. Enable Change for All includes loaded trainers hidden by filters and retains its confirmation, staging, and draft safeguards.
* Zero Trainer move assignments display as Not specified. The editor explains that these are stored assignments rather than a resolved battle moveset; explicit moves and zero values keep their existing storage meaning.

## Editing And Comparisons

* Pokemon compatibility groups offer Enable All, Disable All, and Restore Vanilla, including entries hidden by search. Items bulk compatibility actions follow Show all Pokemon and include entries hidden by search. Compatibility changes remain drafts until staged, Cancel discards them, and failed staging preserves the input.
* Focused learnset rows, encounter slots, and Trainer party slots support Ctrl+C and Ctrl+V through the existing internal editor clipboard. Normal text editing, game compatibility checks, and context menus remain available; external clipboard text cannot become editor records.
* Changes identifies staged shop removals individually, allowing one removal to be restored while keeping other removals, additions, replacements, and ordering. Duplicate items are handled by occurrence, and associated operations keep their atomic removal rules.
* Workbench comparison catalogs search the complete prepared study across all five games, report complete metric counts, and load record details only when selected. Searchable paged choices retain selections, reject stale responses, and let failed reads be retried.

## History And Output

* History has its own page between Changes and Settings. It groups transactions by local date and editor, pages transactions and recorded changes, and keeps long lists within a scrollable area. Older file-only receipts remain readable without inventing individual edit details.
* Existing output stays editable after app updates and configuration changes, including relocated source or support folders. Output history, checkpoints, restore, and supported gameplay package operations remain available for the selected game and output folder.
* Durable output history, ownership, checkpoints, and legacy Mod Merger metadata use separate workspaces for each exact game and output location. Verified migration preserves existing records and resumes interrupted work; unprovable conflicts stay blocked with their copies preserved.
* FAT, FAT32, and exFAT output locations use protected workspace recovery journals while temporary working files stay on the output volume. Existing NTFS protections, project isolation, review checks, and pending recovery safeguards remain in place. Filesystem limits, including FAT32 single-file limits, still apply.

## Themes And Presentation

* Six new themes join Classic, Renegade, and Royal: Sovereign, Arcane, Relic, Sword and Shield, Scarlet and Violet, and Legends Z-A. Their matching emblems and palettes extend across editor controls, tables, selections, diagnostics, and type effectiveness cells while preserving accessibility preferences.
* Page headers center the selected game and align the page title with navigation and optional memory readings. The sticky Pokemon editing bar keeps the selected sprite and name visible, and advanced editor layouts provide more space for controls. Type Chart cells distinguish immunity, resistance, and weakness across themes.
* Trainer item icons use a bundled catalog with dedicated sprites or representative KM category symbols. Unknown items and failed artwork keep numbered fallbacks, None stays empty, and spacing prevents item and Pokemon sprites from colliding.

## Memory And Diagnostics

* Diagnostics shows private RAM, committed memory, and GPU-local VRAM for this KM Editor instance, its workers, and the interface renderer. Independent options show RAM and VRAM beside page titles, with VRAM below RAM. Unsupported readings show unavailable values; integrated graphics may count shared system memory as GPU-local memory.
* Idle disposable worker caches are released sooner when system memory is tight and reload on demand. Active and queued work, session state, and source handles remain protected. Diagnostics and header readings share one sampler that pauses while hidden.
* Source diagnostics retain the useful workflow explanation, severity, and recovery context while keeping technical details bounded. New controls and guidance are available in all seven interface languages, including a saved Show Beta Editors setting that defaults to off.
* Successful output clears repeated pending-validation and preview messages across all five games. Warnings, errors, and current apply instructions remain visible.

## Release Metadata

* Application package, Tauri, Cargo, lockfile, setup, and window title metadata identify KM Editor 2.6.0 consistently.
* The Windows release contains the custom x64 setup executable, its updater signature, the updater manifest, and checksums.
