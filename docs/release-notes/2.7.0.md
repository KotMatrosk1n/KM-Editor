## Highlights

KM Editor 2.7.0 moves to .NET 11 and C# 15, reduces repeated work during editing, and improves memory use. This release also fixes Sword and Shield restoration, expands editor tabs, and adds sanitized bug reports from errors.

## Performance And Runtime

* KM Editor now uses .NET 11 and C# 15 throughout the application and Windows setup. Updated data loading, model conversion, and binary writers reduce temporary allocations.
* Stage, Review, Apply, and refresh load the records being edited and their required dependencies in supported workflows across all four game families. Small edits no longer repeatedly load unrelated installed restoration assets.
* After Apply, the active editor and editors with pending changes or unsaved drafts refresh as needed. Inactive editors reload when opened. Shared and structural edits retain the wider validation they require, and initial catalog loading still reads the complete catalog.

## Sword And Shield

* Prepare Hisuian Qwilfish, Sliggoo, and Goodra from the correct Scarlet and Violet donor files. Basculegion Female and Enamorus Therian Forme show their species names instead of numeric placeholders.
* Restoring Hisuian Sliggoo or Hisuian Decidueye changes only its added regional evolution route. Other Goomy and Dartrix evolution routes and compatible customizations remain intact when enabling, disabling, or removing the restoration.
* Restoration preparation and updates show the full Pokemon form name. Staging reports progress through selected restorations, shared validation, and the catalog refresh.
* Load large Placement catalogs with shared field definitions and choices while retaining every object and its editable values.
* Keep supported retained restoration models editable when the original default model is unavailable. Model color listing also recognizes additional supported texture formats.
* Use selective restoration in Randomizer with the effective Pokemon catalog. Custom gifts recognize compatible installed Held Item Chance changes while retaining source compatibility checks.

## Workspace And Maintenance

* Pokemon, Items, Moves, and Trainers let tab contents expand down the page. Long sections use the main page scroll while the record browser keeps its resize handle and remembered height.
* Generate a sanitized bug report directly from an error, then use Go to Report to reveal the saved JSON file. Reports include bounded summaries of recorded changes and installed restorations without exporting private paths, names, edited values, or file contents.
* Output recovery errors explain the specific metadata, backup, compatibility, access, or storage condition that blocked recovery, with guidance for the affected operation.
* Check for Updates refreshes update metadata and checks the latest stable release when needed. An available update offers Install Update or Open Release without restarting the app.
* Legends Arceus loads the requested record page while keeping the full catalog count. Development builds now require Node 26.13.1 alongside .NET 11 and C# 15.
