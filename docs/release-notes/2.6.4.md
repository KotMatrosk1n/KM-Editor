## Highlights

KM Editor 2.6.4 fixes missing Marnie Wyndon Boosts navigation, compatibility with modified executables, recovery after output deletion, and Gym Uniform Removal patch addresses. Vanilla output and compatible edits remain supported with or without the 60FPS patch.

## Sword And Shield

* Marnie Wyndon Boosts now appears below Fairy Gym Boosts in Advanced Editors.
* ExeFS editors accept compatible code growth while retaining build, layout and instruction checks. Installing, changing or removing one feature preserves unrelated executable edits, including 60FPS changes.
* Pending edits can be reviewed again after generated output is deleted or recreated. A fresh Review rebuilds the change plan; applying an older review still rejects changed files.
* Gym Uniform Removal now writes its IPS patch to the correct executable address. Recognized older patches are marked as legacy. Reinstall Gym Uniform Removal to replace an older patch while preserving other executable edits.

## Scarlet And Violet

* Restoring Fashion Unlock or Hyperspace edits preserves compatible code extensions from Gameplay Settings.

## Mod Merger

* Advanced merging combines compatible executable images with different code section lengths, preserving added code and independent edits. Conflicting edits still require a choice, and incompatible builds or layouts remain rejected.
* Executable images and matching IPS patches compose in the same address space. With verified matching original files, recognized legacy Gym Uniform Removal patches are corrected before composition.

## Release Metadata

* Application, setup, updater and window title metadata identify KM Editor 2.6.4 consistently.
* Welcome Hub highlights and the developer message remain unchanged from 2.6.3.
