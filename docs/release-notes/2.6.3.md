## Highlights

KM Editor 2.6.3 introduces Basic and Advanced mod merging with archive imports and optional package selection. It adds Legends Z-A Behavior and Alpha Size controls, Marnie Wyndon Boosts for Sword and Shield, clearer evolution and relearn moves, and fixes for editing performance, output compatibility and 60 FPS timing.

## Mod Merger

* Combine mod folders and ZIP, RAR or 7z archives for all five games. Basic compares the supplied mods without an original game dump; Advanced uses matching original files to combine independent edits while separating them from unchanged data. Mod Merger is available before project validation.
* Sources containing multiple or optional packages open a separate selection dialog. Choose components, inspect their documentation, and manage the selection later. Author manifests can declare dependencies, required components and alternatives. A merge accepts up to 64 sources and 64 selected packages.
* Supported game tables merge by record and field, with explicit choices for conflicting edits. Textures, audio, models and unsupported formats use complete file choices. Packed containers and descriptors retain their format specific restrictions; the merger does not assume arbitrary byte changes are compatible.
* IPS, IPS32 and supported PCHTXT patches combine by executable address. Advanced can compare compatible executable images against matching originals. Related settings stay together, including Shiny Rate, Hyper Training and Marnie or Fairy Gym outcomes, while independent edits remain separate.
* Review checks trainer identity, EV totals, encounter level bounds, linked party counts and dependent files. Z-A Behavior fields compose independently where supported. Changed inputs or unresolved conflicts require another review before export. Saved package choices, destination history and recovery remain available, and changing packages or output layouts removes only reviewed merger owned files.

## Editing And Output

* Text staging reads the selected data without repeatedly loading unrelated archives. Repeated editing also releases obsolete workflow snapshots, reducing memory growth during long sessions.
* Evolution moves display and accept level 0 across all five games. Native evolution markers are preserved when saving, and unrelated learnset fields remain unchanged.
* Long Windows output paths remain editable after files are created. Repeated Apply, output history and checkpoint restoration retain their protections in deeply nested folders.
* Item Data and Use Flags use the available editor width. Editor confirmations, pending labels and package guidance have improved translations across all seven interface languages, with more specific diagnostics for actionable failures.

## Sword And Shield

* Marnie Wyndon Boosts appears below Fairy Gym Boosts in Advanced Editors. Choose supported stat outcomes for both answers in each of the three Wyndon battles, stage the changes, and restore the original outcomes when needed.
* Marnie and Fairy Gym outcome edits preserve installed 60FPS sequence timing. Applying or removing the timing patch preserves those outcomes and other compatible script edits.
* 60FPS timing now coordinates supported battle sequences, attack windup, cameras, field effects, script waits, movement, messages and menu repeat timing. Recognized older output can be upgraded while preserving unrelated edits. Unsupported cinematics can still require separate timing work.
* Trainer Whiteout accepts compatible executable growth from other tools while retaining its build and instruction checks. Shared script editing preserves independent Raid Dens and other supported changes. Royal Candy customization preserves supported text and visual choices.

## Scarlet And Violet

* Text staging avoids repeated full archive scans, improving the first edit and subsequent changes. Other archive staging operations reuse a fresh source snapshot for the current operation.
* Starmobile edits can be applied repeatedly under long output paths, including after generated output is deleted and recreated. Combined move assignments continue to validate against the final staged move data.

## Legends Z-A

* Behavior appears below Pokemon in Editors. Choose a wild temperament preset, adjust sight, hearing and home range fields, initialize missing wild tags, or restore the selected resource to vanilla. These controls do not guarantee roaming or attacks where encounter templates or other game systems are missing.
* Pokemon includes Alpha Size controls with native scale multipliers, two decimal places for manual input, ordinary midpoint context and exact vanilla restoration. Shared form and gender resources are identified. Required size fields are added automatically for supported forms that did not enlarge by default.
* Learnset rows show level 0 as Evolution. A Relearn checkbox identifies and sets reminder moves without requiring the internal level marker; mastery levels remain independent.
* Behavior and ordinary Pokemon edits participate in shared Review and Apply across the supported output layouts. Restoring Behavior or Alpha Size preserves unrelated fields owned by other edits.

## Interface And Navigation

* Tooltips dismiss correctly after pointer interaction while retaining keyboard focus behavior. Recent tabs and evolution sprites handle additional editing and navigation cases.
* The welcome hub includes the 2.6.3 notes and updated developer message. Contextual help links lead to refreshed merger guides, Z-A Behavior and Marnie Wyndon Boosts documentation.
