## Highlights

KM Editor 2.7.2 adds direct ZA Recomp output, city roaming controls for every Legends Z-A species, and five Fashion Unlock hairstyles. Sword and Shield get fixes for Mega Baxcalibur, restoration audio, and Pokédex crashes. Windows now protects saved Mod Merger drafts.

## Workspace

* Mod Merger saves drafts with Windows account protection and migrates existing drafts automatically.

## Sword And Shield

* Fixed Mega Baxcalibur's display name, Baxcaliburite evolution item, and form data. Use Update Asset on an existing restoration to keep compatible customizations and assignments.
* Restored footsteps and pokemon cries in Sword projects with large restoration sound banks. Use Check Audio to stage the repair for an existing project.
* Fixed a Pokédex crash when loading restored models in Sword and Shield. Stage your current restoration selections, then review and apply the repair in Changes. New restorations and asset updates include the required repairs when needed.

## Legends Z-A

* City roaming is editable for every species. The Behavior editor identifies native city roaming and offers Ground or Hover for species that need a movement preset. City temperament remains a separate setting.
* Fashion Unlock adds all five character hairstyles to the hair salon. Stage and apply the current installation to upgrade an existing Fashion Unlock mod.
* Stage edits in each editor, then open Changes from the sidebar to review and export them together.
* Output for ZA Recomp combines RomFS data and ExeFS patches in a single mod folder. Projects that start with existing Standalone or Trinity edits can use the same output. Enable Code in ZA Recomp to load executable patches.
