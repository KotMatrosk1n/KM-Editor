## Highlights

KM Editor 2.6.2 adds Trainer Whiteout, Trainer Dynamax and Raid Dens controls for Sword and Shield. It improves combined editor output, keeps editing available after generated files are deleted, stages Wild Encounter drafts together, and expands Legends Z-A TM numbering and compatibility editing.

## Editing And Output

* Deleting generated output files or folders no longer prevents valid editing. Missing files fall back to vanilla, and Apply creates only the output required by the pending changes. Deleted saved edits are not replayed from History. Readable existing output and unrelated edits are preserved.
* Combined editor sessions handle shared source files and dependent edits together. Pokemon data and trainer party changes can apply in one operation, and move changes are resolved before dependent Sword and Shield Rental Pokemon or Scarlet and Violet Starmobile edits. Invalid combined edits still prevent partial output.
* Wild Encounter drafts across records and slots now use one Stage Encounter Changes action in every supported game. Copying, pasting and valid draft edits update slot names, sprites, levels and probabilities immediately. Failed staging preserves drafts, and successful staging preserves newer input.
* A failed Apply retains pending edits and diagnostics, clears the obsolete reviewed plan, and leaves the progress indicator at Review. Correct the reported problem and review again before writing.

## Sword And Shield

* Trainer Whiteout is a new Beta editor with a searchable table of 436 trainer records, Yes and No choices, Reset to Vanilla, Enable Whiteout All and Disable Whiteout All. Select anywhere on a row, stage the desired settings, then review and apply through Changes. Disabling whiteout does not turn a defeat into a victory.
* Trainer Whiteout writes the battle scripts and executable callbacks required by the selected trainer settings instead of rewriting every supported script. Shared scripts preserve compatible Raid Dens edits, and executable changes preserve FPS and other registered patch owners. Repeated uses of one trainer record share its setting; generated Battle Tower opponents are outside individual whiteout control.
* Trainer Dynamax is a new Beta editor with independent Enabled and Disabled permissions for the player and opponent, per trainer reset and separate mass actions. Review and Apply stay inside the editor. All 436 roster records can be configured when used as opponents; repeated uses of one record share a setting, and generated Battle Tower battles use the mass settings.
* Dynamax permission is separate from trainer team flags. Team Can Dynamax fields remain in Trainers, and the original Band, Pokemon eligibility and usage checks remain. Verified vanilla permissions are displayed where established; unknown original battle routes are labeled instead of assigned a guessed value. Enabling permission does not guarantee an opponent will choose Dynamax. Trainer Dynamax remains Beta.
* Trainer Dynamax can apply, upgrade or remove its own executable patch while preserving Trainer Whiteout, FPS and other registered executable edits.
* Raid Dens appears under Tools below Profanity Filter Bypass. Disable or restore the entire den interaction, including the den menu, starting a raid there, collecting Watts and using Wishing Pieces. Dens and beams remain visible. Y-Comm joining and Dynamax Adventures remain separate.
* 60FPS Opening and demos now includes evolution, post evolution, title and egg sequences. Absolute frame jump destinations scale with the sequence timeline. Recognized older output can be upgraded or removed, including cleanup when no new timing files need writing. Other cinematic timing and audio synchronization can still vary.
* Gameplay Settings moves Experience Share, Experience Rate and EXP Level Cap into X > Options. Upgrading removes the recognized old PC menu components while preserving saved settings. The package also corrects the runtime mapping failure associated with the old PC entry. Gameplay Settings remains Beta.
* Data Cache preparation reuses the current vanilla work plan and completed progress across ordinary editing and output refresh. Warmup continues away from Project Setup, yields to foreground operations, and avoids rebuilding the text source plan for every item.
* Battle Cafe Rewards uses the shared Start Editing, Stage and Cancel workflow with an action bar that stays visible while scrolling.

## Scarlet And Violet

* Starmobile pending edits remain usable after their generated output is deleted. Apply uses the current vanilla record with the pending changes, without restoring deleted saved edits from History.
* Combined Moves and Starmobile output respects the resulting move availability regardless of staging order. Invalid assignments prevent the combined write.
* The 3D Model Editor better retains surface color in shaded areas under Studio and In Game lighting. This affects preview rendering, not saved materials or game lighting.

## Legends Z-A

* All supported physical TMs, including added TMs, can use TM numbers 1 through 201. Selecting an occupied number swaps numbering with its current owner while preserving stable item identities, taught moves and shop references. Changing only a number does not rewrite Pokemon compatibility.
* An unused TM can receive a move assignment and a new number in the same staged batch. For example, assign Vine Whip to the unused TM201 slot and change it to TM161 before one Review and Apply. Compatibility editing for the newly assigned move becomes available after Apply and reload.
* TM reassignment preserves existing compatibility for the selected move without creating duplicate references. Batches resolve swaps from the original assignments, support moves with no previous compatibility, and allow an added TM to use a move freed by another edit in that batch. Final duplicate TM move assignments remain invalid.
* Vanilla TM restoration matches Pokemon identity and original move membership even after compatibility positions have changed. Compatibility lists can grow when necessary, and unchanged compatibility produces no Personal output.
* Items and Pokemon edits can update shared generated files in successive operations without conflicting ownership claims. Standalone descriptor output includes every affected table, while Trinity Mod Manager and Trinity Bypass retain their own layouts.
* Show Unused Items defaults unchecked and remembers the chosen state across output refresh, project changes and application restart.

## Models And Audio

* Texture recoloring is in Textures. Materials retains material properties, tints and bindings. Selecting a material outlines its visible meshes, and selecting it again can restore that outline. Material and texture Stage and Discard controls appear at the top for the active category.
* Close editor remains available during model drafting and operations. A confirmation lets you stay with your drafts or close and discard unstaged drafts; staged edits remain in Changes. Material scalar labels appear once, and Studio grid controls have clearer spacing.
* Texture tolerance guidance explains that 0 percent matches the source color and 100 percent affects every visible color in the selected texture. Shared textures still affect every part that uses them.
* Sound Studio recognizes supported music track references and categorizes more complete recordings under Music / BGM. Ambiguous uses remain under Other. Playback still auditions individual recordings rather than recreating interactive music events.

## Project Setup And Welcome Hub

* Scarlet, Violet and Legends Z-A require a valid user selected support folder before editors appear, alongside valid base paths. Missing support is reported in Project Setup diagnostics.
* Beta Editors remain hidden until paths are validated and the Beta Editors setting is enabled. Cache status says Not checked and Awaiting path validation before validation begins, then distinguishes path validation from cache checking.
* Install Update can display its confirmation and diagnostics directly in the Welcome Hub. The hub includes the 2.6.2 notes, and navigation titles for Trainer Whiteout, Trainer Dynamax and Raid Dens are available in all seven interface languages.
